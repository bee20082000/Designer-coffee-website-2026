# Designer Coffee Website Remake 2026

A custom WordPress and WooCommerce theme for the 2026 Designer Coffee website remake.

## Repository scope

This repository intentionally tracks only the custom theme in:

`app/public/wp-content/themes/designer-coffee/`

WordPress core, third-party plugins, uploads, database dumps, Local configuration, logs, and secrets are excluded. Those files are environment-specific or reproducible and should not be stored in source control.

## Local development

1. Create or open a WordPress site in Local.
2. Place this repository at the Local site root.
3. Install and activate WooCommerce and any required content plugins.
4. Activate the **Designer Coffee Custom** theme.
5. Import site content separately when needed; uploaded media and database content are not part of this repository.

## Theme documentation

See the [theme maintenance guide](app/public/wp-content/themes/designer-coffee/README.md) for folder responsibilities and coding conventions.
